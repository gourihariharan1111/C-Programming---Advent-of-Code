Solution to Day1 part1

Input: A file containing 2 lists of positive integers which are location ID's.

Output: Total Distance

Steps:

1. Define necessary libraries.
2. Read the input file.
3. Split the lists into 2 arrays - list1 and list2.
4. Sort list1 and list2 independently using qsort (defined in stdlib.h).
   Add a compare function to arrange list items in ascending order.
5. Set total = 0
6. Iterate through each element of list1 and list2 and subtract the corresponding elements to find distance.
   Add this value to total.
7. The final value stored in total is the required output.
